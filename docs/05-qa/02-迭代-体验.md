# 迭代轮 2 — 用户体验（2026-08-02）

## 1. 迭代目标

提升交互流畅度、界面友好性与操作一致性，重点消除**界面文案与 i18n 不一致**（en 界面出现中文）、弹窗交互不统一、时间/状态反馈本地化缺失。

## 2. 迭代范围

| 模块 | 范围 |
|------|------|
| 全仓组件 | 硬编码中文文案审计与 i18n 化 |
| 回收站页（TrashPage） | 标题/按钮/表头/空状态/确认弹窗文案 |
| 仪表盘（Dashboard） | 相对时间、加载失败文案 |
| 全局 | 404 页面、弹窗 Esc/焦点陷阱一致性 |
