# Lumora 产品路线图 (v0.8.0 → v1.0)

> **更新时间**：2026-08-02
> **当前版本**：v0.8.0 已发布 (676 前端测试 + 128 Rust 测试)
> **目标用户**：AI 图片创作者 (Stable Diffusion / ComfyUI / Flux)

---

## 产品愿景

**一句话**：让 AI 图片创作者在海量生成图中快速找到、组织、理解、复用他们的作品。

**核心价值主张**：
1. 🔍 **找得到** — 语义搜索 + 以图搜图 + 全文搜索
2. 🏷️ **管得好** — AI 自动标签 + 变体分组 + 智能收藏
3. 🎨 **看得懂** — AI 分析 prompt/模型/参数 + 色彩提取
4. 📦 **导得出** — 批量导出 + 模板命名 + 格式转换

---

## 版本规划

### v0.8.0 — 体验打磨 (Polish & Performance)

**主题**：把现有功能做到极致，解决用户痛点
> **状态**：✅ 已发布（2026-08-02，GitHub Release 三平台安装包 + 自动更新；QA 报告体系见 `docs/05-qa`）

| 功能 | 优先级 | 说明 | 预估工作量 |
|------|--------|------|-----------|
| **变体对比视图** | P0 | 同 prompt 不同 seed 的图片并排对比 | 3 天 |
| **高级筛选面板** | P0 | 组合条件：模型 + 日期范围 + 评分 + 尺寸 | 2 天 |
| **批量重命名** | P1 | 按模板批量重命名文件（导出前处理） | 1 天 |
| **图片信息增强** | P1 | 显示完整 SD 参数（Steps, CFG, Sampler, Seed） | 1 天 |
| **性能优化** | P1 | 10K+ 图片场景下的虚拟滚动优化 | 2 天 |
| **键盘快捷键完善** | P2 | 全局快捷键 + 快捷键帮助面板 | 1 天 |
| **错误恢复** | P2 | 图片加载失败自动重试 + 离线状态提示 | 1 天 |

**验收标准**：
- [x] 变体组图片可并排对比（2-6 张）
- [x] 筛选面板支持 3+ 条件组合
- [ ] 10K 图片库滚动帧率 ≥ 30fps（TC-PERF-002，需人工验收后勾选）
- [x] 所有现有测试通过 + 新增 30+ 测试

### v0.9.0 — 核心能力深化 (Core Deepening)

**主题**：围绕“找得到、管得好、看得懂、导得出”把核心链路做到可用、可信、可规模化
> **状态**：开发中（2026-08-03）；非核心方向（图片编辑/水印/EXIF）已移出路线图——Lumora 是图库管理器，不是图片编辑器

| 功能 | 优先级 | 说明 | 预估工作量 |
|------|--------|------|-----------|
| **语义搜索端到端** | P0 | 嵌入索引管理：批量/增量嵌入、进度可视化、搜索质量与速度调优 | 4 天 |
| **智能相册** | P0 | 基于规则自动分组（模型、日期、评分、标签组合） | 3 天 |
| **AI 分析增强** | P1 | 批量分析、参数/色彩检索维度、分析结果沉淀复用 | 3 天 |
| **以图搜图实测调优** | P1 | CLIP 端到端验证、相似度阈值与结果排序优化 | 2 天 |
| **收藏夹增强** | P1 | 多收藏夹 + 嵌套分类 | 2 天 |
| **10K 性能收口** | P1 | TC-PERF-002 人工验收 + 启动/滚动/搜索/筛选全链路基准 | 2 天 |
| **Prompt 模板库** | P2 | 保存常用 prompt 片段，快速复用（创作工作流） | 1 天 |
| **更新体验** | P2 | 更新横幅 + 一键更新流程（UpdateBanner，源自用户反馈） | 1 天 |

**验收标准**：
- [x] 语义搜索在 10K 图库 < 1.5s（实测 68ms，见 `docs/04-deploy/10k-semantic-bench.md`），支持增量嵌入索引
- [x] 智能相册支持 5+ 规则类型（模型 / 评分 / 格式 / Prompt / 标签，已开发）
- [x] 语义搜索/以图搜图在真实 Ollama+CLIP 环境端到端通过（2026-08-14 实测，含 CLIP 独立 512 维索引修复）
- [x] 10K 图片库滚动帧率 ≥ 30fps（TC-PERF-002：自动化基线 p95 7.6ms ≈ 131.6fps，见 `docs/04-deploy/10k-semantic-bench.md`；发布前可在 VM 复验）
- [x] 新增 50+ 测试（前端 676→742、Rust 128→206）

## 依赖关系

```
v0.8.0 (体验打磨)
  ├── 变体对比视图 ← 依赖现有 variant_groups
  ├── 高级筛选 ← 依赖现有 search_images_advanced
  └── 性能优化 ← 依赖现有 LazyLoad + VirtualGrid

v0.8.1 (启动体验)
  ├── 品牌启动动画 ← 依赖现有 design tokens + CSS keyframes
  └── 无缝加载 ← 依赖现有 lazy 路由体系

v0.9.0 (核心能力深化)
  ├── 语义搜索端到端 ← 依赖现有 embeddings + Ollama/CLIP
  ├── 智能相册 ← 依赖现有 tag + rating + filters
  └── AI 分析增强 ← 依赖现有 ai + analysis 命令

v1.0 (生产就绪)
  ├── 插件系统 ← 依赖 Tauri plugin API
  ├── 多 AI 后端 ← 依赖现有 Ollama 集成
  └── 数据迁移 ← 依赖现有 import_images
```
