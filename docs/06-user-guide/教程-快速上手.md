# Lumora 教程：快速上手

> 面向新用户：从安装到会用，约 10 分钟。所有功能均可离线使用（AI 功能除外）。

## 1. 安装

1. 从 [GitHub Releases](https://github.com/hyls9527/Lumora-clean/releases) 下载 **Windows**：`Lumora_*_x64-setup.exe`（macOS 选 `.dmg`，Linux 选 `.AppImage`）
2. 双击安装并启动
3. 以后升级走**应用内自动更新**（启动时自动检查，签名验证后提示安装）

## 2. 准备 AI 后端（可选，建议先做）

Lumora 的搜索与分析可以在本地 Ollama 或 OpenAI 兼容服务上运行：

**方案 A：本地 Ollama（推荐，免费离线）**
```bash
# 安装 Ollama 后拉取模型
ollama pull nomic-embed-text   # 语义搜索嵌入
ollama pull llava              # 图片分析（自动标签/描述）
```

**方案 B：OpenAI 兼容 API**（OpenAI / DeepSeek / Azure / 本地 vLLM / llama.cpp）

打开 **设置 → AI 后端**：
- 「推理与嵌入服务」= 嵌入后端（语义搜索）
- 「视觉分析服务」= 图片分析后端（可独立于嵌入选择）
- 填 Base URL / API Key / 模型名（本地回环地址如 `http://127.0.0.1:11434` 可留空 API Key）

## 3. 导入图片

把文件夹或图片**直接拖进窗口**即可。Lumora 自动提取元数据（模型、Prompt、Seed、尺寸、日期），相同 Prompt 的图片归入同一**变体组**。

## 4. 找到你的图（三种搜索）

| 方式 | 操作 | 说明 |
|---|---|---|
| 语义搜索 | 顶部搜索框输入描述 | 如 "红色的跑车"、"海边日落"——由嵌入后端理解语义 |
| 以图搜图 | 选中图片 → 视觉相似 | CLIP 索引，无需文字 |
| 精确筛选 | 高级筛选 | 按模型 / 格式 / 评分 / 日期 / Prompt 关键词 / 标签组合 |

> 首次使用语义搜索或以图搜图，需要先构建索引（自动提示，或仪表盘/搜索页「补齐索引」）。嵌入后端切换后索引维度可能变化，需重建（应用会提示）。

## 5. AI 分析：自动标签与描述

选中图片 → 触发「AI 分析」（设置页可确认视觉后端已配置）。Lumora 会生成：
- **描述**（2-3 句）
- **标签**（含置信度）——自动关联到图片
- **评分**（夯 / 稳 / 拉 三档；同 Prompt 变体组内显示 HPS 组内比较）

## 6. 组织你的库

- **标签**：图片上打标签，之后按标签筛选/搜索
- **收藏**：一键收藏，收藏夹快速访问
- **评分**：1-5 星（键盘或右键）
- **智能收藏**：规则自动分组——按模型/格式/评分/日期/Prompt/标签/审美档位组合（见使用指南 §7）
- **回收站**：删除进回收站可恢复，彻底删除需确认

## 7. 导出

选中图片 → 导出：
- **格式转换**：JPG / WebP / AVIF，可调质量与尺寸
- **文件名模板**：如 `{model}_{rating}_{seed}`（占位符见使用指南 §8）
- **批量重命名**：按模板批量改名（可预览）

## 8. 备份

**设置 → 备份**：导出整个数据库（图片文件不动，备份的是索引/标签/评分元数据）。恢复时从备份文件导入。
