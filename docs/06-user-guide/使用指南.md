# Lumora 使用指南

> 面向 AI 图像创作者的功能参考。版本：v0.10.1。核心原则：**AI 是主体，不是按钮**——评分等主观判断永远由你决定。

## 1. 界面概览

| 区域 | 功能 |
|---|---|
| 顶部工具栏 | 搜索、命令面板（`⌘K`）、批量操作 |
| 左侧边栏 | 收藏夹、智能收藏、标签、回收站入口 |
| 主区域 | 图片瀑布流（支持键盘导航） |
| 详情视图 | 元数据、变体组、标签、评分、分析结果 |

**快捷键**：`⌘K` 命令面板 · `⌘A` 全选 · `Delete` 删除 · `Esc` 取消选择。方向键在画廊与侧边栏导航。

## 2. 导入

- 拖拽文件夹/文件到窗口；重复路径自动忽略
- 自动提取：模型、Prompt、Seed、尺寸、创建时间、格式
- 相同 Prompt 的图片自动归入**变体组**（组内可比较 HPS）

## 3. 搜索

### 3.1 语义搜索
描述性查询（如 "赛博朋克城市夜景"），由嵌入后端（Ollama `nomic-embed-text` 或 OpenAI 兼容）计算向量相似度。

### 3.2 以图搜图（CLIP）
按视觉相似度找图（"这张像什么"），索引 512 维 CLIP 向量，本地生成，与 AI 后端无关。

### 3.3 高级筛选
按模型、格式、评分（≥/≤）、日期（≥/≤，含整日）、Prompt 关键词、标签组合过滤。

### 3.4 索引说明
- 语义索引：768 维；以图搜图索引：512 维——两者独立
- 缺失统计与「补齐索引」入口在仪表盘/搜索页
- 嵌入后端切换后维度可能不同（如 `text-embedding-3-small` 为 1536），需删除旧向量或用「补齐索引」重建——应用会自动校验维度并提示

## 4. AI 分析

**后端配置**（设置 → AI 后端）：
- `推理与嵌入服务`：语义搜索的后端
- `视觉分析服务`：图片分析的后端——可与嵌入后端独立（例如嵌入用 Ollama、视觉用本地 llama.cpp）
- 本地回环地址（localhost / 127.0.0.1 / [::1] / 0.0.0.0）免 API Key；视觉请求超时 300s

**分析产出**：描述、标签（含置信度 0-1）、主物体、配色、构图分析。分析历史保存在详情页。

**评分**：
- 1-5 星主观评分（永远人工）
- AI 审美分 + 三档标签：**夯 / 稳 / 拉**
- **HPS**：仅在同 Prompt 变体组内展示（跨组比较无意义），标注「组内」「仅同 prompt 变体内可比」

## 5. 组织

| 功能 | 说明 |
|---|---|
| 标签 | 创建、批量关联；按标签筛选 |
| 收藏 | 一键收藏，列表视图 |
| 评分 | 1-5 星，可筛选 |
| 变体组 | 同 Prompt 分组；组内最佳展示 |
| 智能收藏 | 规则自动分组，实时匹配，见 §7 |
| 回收站 | 软删除可恢复；清空/彻底删除级联清理关联数据 |

## 6. 导出与转换

- **格式**：JPG / WebP / AVIF（可调质量、尺寸）
- **文件名模板**：见 §8；输出自动清理非法字符
- **批量重命名**：模板批量改名，冲突自动加后缀/时间戳，支持 dry-run 预览

## 7. 智能收藏规则

每条规则 = 字段 + 操作符 + 值；多条规则 **AND** 组合（全部满足才命中）。

| 字段 | 操作符 | 值示例 |
|---|---|---|
| `model` | equals | `SDXL` |
| `format` | equals | `png` |
| `rating` | gte / lte | `4` |
| `score` | equals | 档位：`夯` / `稳` / `拉` |
| `date` | gte / lte | `2026-08-01`（含结束日当天） |
| `prompt` | contains | `sunset` |
| `tag` | equals / in | `cat` 或 `cat,dog`（逗号分隔） |

## 8. 导出文件名模板占位符

| 占位符 | 含义 |
|---|---|
| `{name}` | 原文件名（默认模板） |
| `{id}` | 库内 ID |
| `{date}` | 创建日期（YYYY-MM-DD） |
| `{rating}` | 1-5 星 |
| `{tags}` | 标签（逗号分隔） |
| `{model}` / `{prompt}` / `{seed}` | 元数据（缺省为空） |
| `{width}` × `{height}` | 尺寸 |
| `{format}` | 文件格式 |

示例：`{model}_{rating}_{seed}` → `SDXL_4_42`；`{date}/{name}` → `2026-08-15/photo`

## 9. 设置

- **AI 后端**：嵌入/视觉双后端独立切换；Base URL / Key / 模型；环境变量兜底（`LUMORA_AI_PROVIDER`、`LUMORA_VISION_PROVIDER`、`OPENAI_BASE_URL` 等）
- **语言**：中文 / English
- **主题**：浅色 / 深色
- **备份**：数据库整库导出/恢复

## 10. AI 客户端接入（MCP）

Lumora 内嵌 MCP 服务端（`http://127.0.0.1:{端口}/mcp`，局域网 token 鉴权）——Claude、Cursor 等可**浏览、搜索、读取**你的图库，并管理标签/收藏/回收站。**评分保持人工，不向 AI 开放**。详见 `docs/04-deploy/mcp.md`。

## 11. 自动更新

启动时检查 GitHub Releases（minisign 签名验证）。更新流程：提示 → 后台下载 → 重启安装。所有安装包均带签名，未经签名的产物不会通过验证。

## 12. 故障排除

| 现象 | 处理 |
|---|---|
| 搜索无结果 / 提示索引缺失 | 仪表盘或搜索页「补齐索引」；嵌入后端切换后需重建（维度校验会提示） |
| AI 分析失败「后端未配置」 | 设置 → AI 后端确认 provider；OpenAI 兼容非回环地址需 API Key |
| Ollama 分析超时 | 视觉请求超时 300s，本地大模型推理慢属正常；确认模型已 `ollama pull llava` |
| 以图搜图无结果 | CLIP sidecar 依赖 Python 环境（`LUMORA_PYTHON` 可指定解释器） |
| 更新不提示 | 确认已发布版本可用；检查网络；签名验证失败会拒绝安装 |

## 13. 数据与隐私

- 全部数据存本地 SQLite（`settings.json` + 数据库文件）
- API Key 只存本地设置，不进日志、不上传
- 图片分析仅在**你配置的后端**进行（本地 Ollama 或你指定的 API）
